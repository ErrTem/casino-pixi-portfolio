## Phase Goal

**As a** recruiter playing the demo, **I want to** see a rising curve with a small rocket on the path and a clear crash break driven only by GameLogic snapshots, **so that** the round reads as a Crash spectacle.

This restates the existing ROADMAP goal. It does not add scope.

<objective>
Mount PixiJS v8 into `#game-canvas-host`, replace the rAF clock with one capped ticker, and draw a production neon trail plus a small rocket that follows `snapshot.multiplier`. A climb-to-waiting edge severs the path and hides the rocket. Hold and fade timers live in a pure reducer so later plans only add atmosphere and the cash-out latch display.

Purpose: Prove VIS-01 success criteria 1–3 on a crash round before spectator-finish and idle art.
Output: `pixi.js@8.21.0` pinned, rAF deleted, Vitest green for path slope and view-mode transitions.
Decisions in this plan: D-01, D-02, D-03, D-06, D-07, D-09, D-11, D-12, D-18. D-16 view side: `cashed_out` already counts as climb so plan 03-02 does not rewrite path-follow.
</objective>
