## Phase Goal

**As a** portfolio visitor playing HOTLINE, **I want to** risk a base line win on VHS SURVIVE/DIE after settle, **so that** I can double or lose that win up to ten rounds without gambling bonus totals.

Purpose: Production-quality tracer through Zod features.gamble, pure createGamble, Wallet.debit, and HotlineGame baseLineWinCents APIs. No DOM or session in this plan.
Output: Required gamble config; createGamble; Wallet.debit; HotlineGame gamble facade; Vitest for pot math, DIE debit, and base-only stake capture.
</objective>

<interfaces>
Contracts this plan creates (consumed by 05-02 and 05-03):
- features.gamble: { maxRounds: positiveInt, surviveChance: chance01 } required on featuresSchema; sample JSON { maxRounds: 10, surviveChance: 0.5 }
- createGamble({ maxRounds, surviveChance }) returns { offer(stakeCents), clear(), resolve(rng), snapshot() }
- GambleResolve: { survived, stakeCents, roundsDone, offered }
- GambleSnapshot: { stakeCents, roundsDone, offered }
- resolve(rng): rng.next() less than surviveChance means SURVIVE (stake becomes stake times 2, roundsDone plus 1, offered stays true while roundsDone less than maxRounds); else DIE (offered false, stake 0); returns null when not offered or rounds already at max
- Wallet.debit(amountCents): boolean — integer positive amount that fits balance, then subtract
- HotlineGame: on base spin only set baseLineWinCents to sum of lineWins; clear on next base spin start and on clearGambleOffer when not chaining; APIs clearGambleOffer(), resolveGamble(rng), getGambleSnapshot(); snapshot may expose gamble fields
</interfaces>
