## Phase Goal

**As a** portfolio visitor playing HOTLINE, **I want to** risk a base line win on VHS SURVIVE/DIE after settle, **so that** I can double or lose that win up to ten rounds without gambling bonus totals.

<objective>
**As a** portfolio visitor with a settled base line win, **I want** Gamble on the HUD to open a VHS SURVIVE/DIE overlay that resolves against a seeded pot and returns me to the base HUD, **so that** GAMBLE-01 and GAMBLE-02 work end to end.

Purpose: Production-quality tracer from Zod `features.gamble` through pure `createGamble`, Wallet debit, HotlineGame stake capture, session idle offer, HUD Gamble control, and DOM VHS overlay. Lands costly D-01 offer timing in the busy FSM.
Output: Required gamble config; createGamble; Wallet.debit; HotlineGame gamble APIs; GambleOverlay; session offer and Spin-clear; Vitest for pot math, DIE debit, and offer gating greps.
</objective>

<precondition>
Phase 4 complete: nights drain through FeatureOverlay; enterIdle exists; base HotlineGame.spin credits line wins before collectors and nights.
</precondition>

<interfaces>
Contracts this plan creates (consumed by 05-02 through 05-04):
- features.gamble: { maxRounds: positiveInt, surviveChance: chance01 } required on featuresSchema; sample JSON { maxRounds: 10, surviveChance: 0.5 }
- createGamble({ maxRounds, surviveChance }) returns { offer(stakeCents), clear(), resolve(rng), snapshot() }
- GambleResolve: { survived, stakeCents, roundsDone, offered }
- GambleSnapshot: { stakeCents, roundsDone, offered }
- resolve(rng): rng.next() less than surviveChance means SURVIVE (stake becomes stake times 2, roundsDone plus 1, offered stays true while roundsDone less than maxRounds); else DIE (offered false, stake 0); returns null when not offered or rounds already at max
- Wallet.debit(amountCents): boolean — integer positive amount that fits balance, then subtract
- HotlineGame: on base spin only set baseLineWinCents to sum of lineWins; clear on next base spin start and on clearGambleOffer when not chaining; APIs clearGambleOffer(), resolveGamble(rng) or session-owned rng from createRng(`${seed}:gamble`), getGambleSnapshot(); snapshot may expose gamble fields
- PresentPhase gains "gamble"
- mountGambleOverlay(screen, { onSurvive, onDie }) returns { show({ currentWin, gambleToWin }), showResult({ survived, amount }), hide(), dispose() }; textContent only; CSS neon chrome OK if PNGs absent
- HotlineHud: data-action=gamble, setGambleEnabled(boolean); busy disables Gamble with Spin and bet
- enterIdle: if getGambleSnapshot().offered or (baseLineWinCents greater than 0 and not night active) enable Gamble; else disable
- hudGame.spin: clearGambleOffer and setGambleEnabled(false) before game.spin when not busy
</interfaces>
